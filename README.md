# Romancha Homebrew Tap

Homebrew casks for apps by [Romancha](https://github.com/Romancha).

## TimelyMeet

[TimelyMeet](https://github.com/Romancha/timelymeet) — fullscreen meeting alerts with one-click join for macOS.

```bash
brew install --cask romancha/tap/timelymeet
```

Update:

```bash
brew upgrade --cask timelymeet
```

The cask installs the notarized DMG from [GitHub Releases](https://github.com/Romancha/timelymeet/releases). TimelyMeet is also available on the [Mac App Store](https://apps.apple.com/app/timelymeet/id6751949087); install only one of them.
